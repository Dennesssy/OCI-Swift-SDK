# OCI Swift SDK

A Swift port of the [Oracle Cloud Infrastructure Go SDK](https://github.com/oracle/oci-go-sdk), produced by mechanical Go→Swift conversion. Every generated source file carries Oracle's original copyright header and the comment `Code generated by Go to Swift conversion; DO NOT EDIT` — this is a transpile of Oracle's official, code-generated SDK, not a hand-written client.

This is **not affiliated with, endorsed by, or supported by Oracle**. It carries no official support guarantee; use it at your own risk against OCI's APIs.

## What this is (and isn't)

- **Is**: full service-surface coverage mirroring `oci-go-sdk` — ~190 service targets (compute, identity, object storage, database, container engine, generative AI, and the rest of Oracle's public OCI API surface), generated rather than curated.
- **Isn't**: a hand-crafted, idiomatic-Swift-first SDK. If you want that, see [iliasaz/oci-swift-sdk](https://github.com/iliasaz/oci-swift-sdk), a community-maintained, MIT-licensed Swift SDK built from scratch with a smaller, curated service set and Swift-native ergonomics (async/await-first design, OKE Workload Identity, session-token auth, etc.).

Pick this repo when you need broad OCI service coverage that tracks Oracle's own generator output. Pick `iliasaz/oci-swift-sdk` when you want fewer services but a more Swift-idiomatic API.

## Structure

Each top-level directory is one generated service target (e.g. `core/`, `identity/`, `objectstorage/`, `containerengine/`), matching `Package.swift`'s `generatedServiceTargets` list. Do not hand-edit files under these directories — regenerate them from `oci-go-sdk` instead.
