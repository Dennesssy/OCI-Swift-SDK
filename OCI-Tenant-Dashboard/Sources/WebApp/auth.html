Session Token Authentication

Session tokens are generated via OCI CLI:

oci iam auth create-token --name "Dashboard Token"

Cloud Shell Delegation Token

When running in OCI Cloud Shell, authentication is automatic.

If you have a delegation token from Cloud Shell:

cat $OCI_CLI_AUTH_SECURITY_TOKEN_FILE

How to generate API keys:

  1. Open Terminal on your Mac
  2. Run: mkdir ~/.oci && cd ~/.oci
  3. Generate key: openssl genrsa -out oci_api_key_private.pem 2048
  4. Get public key: openssl rsa -pubout -in oci_api_key_private.pem -out oci_api_key_public.pem
  5. Get fingerprint: openssl rsa -pubout -outform DER -in oci_api_key_private.pem | openssl md5 -c
  6. Upload oci_api_key_public.pem to OCI Console → Identity → Users → API Keys
  7. Copy the fingerprint shown in OCI Console
