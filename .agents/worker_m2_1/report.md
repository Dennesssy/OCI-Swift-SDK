## What it does (all parsed from Go source, nothing hardcoded per service)
- Parses *_request_response.go structs and tags (contributesTo path/query/header/header-collection/body, presentIn body/header/header-collection, encoding, mandatory, prefix, collectionFormat), including embedded body fields (e.g. audit GetConfigurationResponse).
- Parses *_client.go: public op -> private impl via common.Retry target (and the no-request form, e.g. identity ListRegions), HTTP method + path template from request.HTTPRequest / MakeDefaultHTTPRequest, BasePath, endpoint template, retry-token auto-generation, doc comment.
- Emits per Go client file: <file>_client.swift with a final class (init(host:signer:http:) and init(region:...)) and one async method per op that builds OCIRequest(method:path:query:headers:body:) and calls base.callRaw; response decoded from body (JSON/binary/plain-text) and response headers (typed: String/Int/Int64/Double/Float/Bool/Date/enum, header-collection) into the Response struct via its memberwise init, in the init-label order of the existing Swift struct.
- Emits oci_gen_support.swift (internal enum OCIGen: path escaping, query/header stringification of optionals/enums/Dates/arrays, JSON enc/dec with RFC3339 dates, header parsing incl. RFC1123).
- Compares against the existing Swift service dir: uses existing Request/Response structs when they have properties (validates every Go field against the Swift property, tolerant case-insensitive match, reports missing/type-mismatched). Empty placeholder structs (objectstorage generated_request_response_stubs.swift) count as missing; types are then generated from the Go structs (disable with --no-emit-missing-types). Referenced model/enum types not declared anywhere in the Swift dir are listed in gen_report.json (missing_types).
